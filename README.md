# Retail Sales Analysis & Prediction

A retail sales analysis and machine learning project using Python,
Pandas, NumPy, Seaborn, Matplotlib, and Scikit-Learn.

## Overview

This project analyzes historical retail sales data and builds
machine learning models to predict weekly sales.

## Workflow

- Data Loading
- Data Integration
- Data Preprocessing
- Exploratory Data Analysis
- Data Visualization
- Feature Analysis
- Machine Learning
- Model Evaluation
- Sales Prediction

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Jupyter Notebook

## Project Files

- `retail_sales_prediction.ipynb` - Complete analysis and machine learning workflow
- `requirements.txt` - Python dependencies
